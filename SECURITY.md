# Security Policy

## Supported versions

Security fixes are intended for the latest released version. Users should
upgrade to the latest release before reporting an issue.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through
[GitHub's private vulnerability reporting for this repository](https://github.com/Adil-MohammedK/bmtcapp-ntfy/security/advisories/new).
If private reporting is unavailable, contact the maintainer through the
[maintainer's GitHub profile](https://github.com/Adil-MohammedK). Do not disclose
vulnerabilities in public issues, discussions, or pull requests until the
maintainer has had a chance to investigate.

Include the affected version, a description of the impact, and steps to
reproduce the issue where possible. Avoid including real credentials or
personal data. You will receive a response as soon as the maintainer is able to
review the report; no fixed response or resolution time is guaranteed.
